# Manoj Portfolio Website

This is a personal portfolio website built with HTML, CSS, and JavaScript. It showcases the owner's profile, education, projects, and contact information.

## Project Structure

- `index.html` — Home page
- `education.html` — Education details page
- `connect.html` — Contact/connection page
- `styles.css` — Main styling for the site
- `script.js` — JavaScript for interactive behavior

## Features

- Responsive portfolio layout
- Multiple pages for profile and education details
- Contact section for communication
- Clean, modern styling

## How to Run

Since this is a static website, you can open it directly in a browser:

1. Open `index.html` in your browser, or
2. Run a local web server from this folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

You can update the personal information, education details, and contact links by editing the HTML files and styles in the project.
